# Web3 Token Price Alert Bot

This is a simple Web3 project.  
It helps you track crypto token prices and get alerts when prices change.

This project is made for beginners who want to learn how blockchain data and price APIs work.

## What This Project Does
- Track a token symbol
- Check token price
- Compare old and new price
- Show alert in console
- Save price history to file

## Tools Used
- Node.js
- Simple JavaScript
- Public crypto price API
- Local JSON file for data storage

## How To Install
1. Install Node.js
2. Download this repository
3. Open terminal in project folder
4. Run:
   npm install
5. Start the app:
   node app.js

## Folder Structure
- app.js = main file
- config.js = project settings
- price.js = price checker
- alert.js = alert system
- api.js = price API calls
- data/ = saved price history
- logs/ = alert logs

## Example Use
- Set token symbol
- App checks price
- App shows alert if price changes
- App saves price history
